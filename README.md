<a id="etapa-1"></a>
## Etapa 1: Conocer a la persona

Antes de comenzar, conviene hacer una pequeña entrevista:

* ¿Por qué quiere aprender informática?
* ¿Tiene experiencia previa?
* ¿Cuánto tiempo puede estudiar por semana?
* ¿Le interesa trabajar, estudiar una carrera o aprender por curiosidad?
* ¿Qué cosas le llaman más la atención?
* ¿Prefiere crear páginas, aplicaciones, videojuegos o trabajar con datos?
* ¿Cuenta con una computadora?
* ¿Qué edad tiene y cuál es su nivel educativo?

Esto permite elegir un recorrido adecuado y evitar que empiece con tecnologías que todavía no necesita.

<a id="motivaciones"></a>
## Posibles motivaciones y recorridos

* **Quiero descubrir si me gusta programar** — Fundamentos + proyectos cortos.
* **Quiero crear páginas web** — HTML + CSS + JavaScript.
* **Quiero trabajar como programador** — Python, Java o JavaScript + Git.
* **Quiero automatizar tareas** — Python + archivos + Excel.
* **Quiero crear videojuegos** — Lógica + Python + Pygame.
* **Quiero aprender computación general** — Sistema operativo + archivos + internet + programación básica.

<a id="caminos"></a>
# Caminos

No hay un tronco común único: cada camino empieza desde cero, pero directamente en el
lenguaje que se va a usar (evita enseñar la lógica dos veces, una genérica y otra en el
lenguaje elegido). Los temas base (variables, condicionales, ciclos, funciones) se repiten
en todos los caminos, solo cambia el lenguaje y el ritmo.

Plan completo (13 semanas de base): [Web/README.md](Web/README.md)

<a id="camino-java"></a>
## Camino 3: Java, orientado a objetos

Plan completo: [Java/README.md](Java/README.md). El eje del camino es la Programación
Orientada a Objetos (semana 11, con teoría en PDF y ejercicios propios en [POO/readme.md](POO/readme.md) —
no es una sola semana, es su propio curso completo): las semanas 1-10 son la base de
lógica y sintaxis para llegar preparado, y la especialización en Backend con Spring Boot
(semanas 12-13 + Maven/Git) es esa misma POO aplicada a un framework real.

**Objetivo final:**
Dominar el paradigma orientado a objetos (clases, encapsulamiento, herencia, polimorfismo)
usando Java como vehículo, y aplicarlo en una API REST simple con Spring Boot.

<a id="objetivos-por-nivel"></a>
# Objetivos por nivel

## Nivel inicial

* Comprender qué es un algoritmo.
* Crear programas sencillos.
* Usar variables y operadores.
* Resolver condiciones.
* Utilizar ciclos.
* Leer y corregir errores básicos.

## Nivel intermedio

* Dividir problemas en módulos.
* Trabajar con colecciones de datos.
* Utilizar archivos.
* Resolver ejercicios sin copiar una solución.
* Usar Git para guardar proyectos.
* Completar proyectos pequeños.

## Nivel avanzado inicial

* Diseñar una aplicación completa.
* Utilizar una base de datos.
* Consumir una API.
* Leer documentación.
* Organizar correctamente el código.
* Publicar y presentar un proyecto.

<a id="rutina-semanal"></a>
# Rutina semanal recomendada

Para alguien que dispone de cuatro horas por semana:

* **Día 1 — 1 hora:** aprender un concepto.
* **Día 2 — 1 hora:** realizar ejercicios guiados.
* **Día 3 — 1 hora:** resolver ejercicios sin ayuda.
* **Día 4 — 1 hora:** avanzar con un proyecto personal.

La proporción ideal sería aproximadamente:

* 30 % teoría.
* 50 % práctica.
* 20 % proyecto personal.

<a id="seguimiento-objetivos"></a>
# Seguimiento de objetivos

Cada objetivo debería ser pequeño y comprobable.

En lugar de:

> “Aprender programación.”

Conviene plantear:

> “Esta semana voy a crear tres programas que utilicen variables y condicionales.”

Para cada semana se puede registrar:

* [ ] Miré o leí el contenido.
* [ ] Realicé los ejercicios guiados.
* [ ] Resolví al menos dos ejercicios sin ayuda.
* [ ] Pude explicar el tema con mis palabras.
* [ ] Apliqué el contenido en mi proyecto.
* [ ] Anoté las dudas que todavía tengo.

La idea central del plan sería: **elegir un camino cuanto antes y avanzar despacio dentro de él**, en el lenguaje que se va a usar de verdad. Así la persona no se abruma y puede ver avances concretos desde las primeras semanas.
